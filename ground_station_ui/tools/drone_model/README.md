# EIU drone 3D model (GCS 3D page)

Built by a parametric Blender script → `.glb` → `pyside6-balsam` → `qml/models/eiu_drone/EiuDrone.qml`.
The 3D page (`qml/pages/View3DPage.qml`) uses `EiuDrone { scale: 100 }` inside the `base_link` node; the map
uses the same model when tilted, and `images/drone_top.png` when viewed from above.

| File | Purpose |
|---|---|
| `build_drone.py` | builds the drone from `PARAMS` (mm, top of the file): frame, arms, SunnySky motors, props, legs, box, lidar, GPS |
| `build.sh` | rebuilds everything: Blender → glb → balsam → `qml/models/eiu_drone/` + preview images |
| `c12.glb` | real **Skydroid C12** gimbal (from the GrabCAD STEP, decimated) |
| `x2216.glb` | real **SunnySky X2216** motor (GrabCAD STEP), used for all four motors |
| `gps_m9n.glb` | **Holybro M9N** GPS (same housing as the M10 on the drone), on the rear mast, arrow towards the nose |
| `step2stl.py`, `convert_part.py` | STEP → `.glb` conversion (presets `c12`, `x2216`, `gps_m9n`); only needed when a STEP file changes |
| `add_halo.py` | adds a light halo to `images/drone_top.png` |

Generated by `build.sh` and not committed (`.gitignore`): `eiu_drone.blend` (Blender scene for manual edits)
and `preview*.png` (quick previews). The original STEP files are not in the repo (copyright of their GrabCAD
authors).

**Axes**: X = nose (gimbal side; the GPS arrow points this way), Y = left, Z = up, metres, **origin = PX4
board (`base_link`)**. Lidar scan plane is 115 mm above the PX4 (matches the TF in
`drone_bringup/launch/static_tf.launch.py`).

## Rebuild after editing `PARAMS`

```bash
cd ~/drone_ws/src/ground_station_ui && ./tools/drone_model/build.sh
```
Requires **Blender 5.x at `/snap/bin/blender`** (the apt 3.0 build in `/usr/bin/blender` is too old).
Restart the app to see the changes.

## Replacing a part's STEP file (rarely needed)

Download the STEP files from GrabCAD into `tools/drone_model/` (Skydroid C12, SunnySky X2216, Holybro M9N).
Blender cannot read STEP, so gmsh (OpenCASCADE) meshes it into one STL per volume:
```bash
pip download --no-deps gmsh -d /tmp/gmsh && cd /tmp/gmsh && unzip -q gmsh-*.whl -d x
python3 tools/drone_model/step2stl.py /tmp/gmsh/x "tools/drone_model/Камера Skydroid C12.stp" /tmp/c12_parts
/snap/bin/blender --background --python tools/drone_model/convert_part.py -- c12 /tmp/c12_parts tools/drone_model/c12.glb
python3 tools/drone_model/step2stl.py /tmp/gmsh/x "tools/drone_model/Sunnysky X2216 Motor.STEP" /tmp/x2216_parts
/snap/bin/blender --background --python tools/drone_model/convert_part.py -- x2216 /tmp/x2216_parts tools/drone_model/x2216.glb
python3 tools/drone_model/step2stl.py /tmp/gmsh/x "tools/drone_model/GPS Holybro M9N.step" /tmp/gps_parts
/snap/bin/blender --background --python tools/drone_model/convert_part.py -- gps_m9n /tmp/gps_parts tools/drone_model/gps_m9n.glb
./tools/drone_model/build.sh
```
`convert_part.py` rotates the STEP into drone axes (front = +X, up = +Z), converts mm → m, sets the origin
(C12: top of the mount plate; X2216: centre of the base), assigns colours by volume number (`step2stl.py`
prints each volume's bbox) and decimates. If a `.glb` is missing, `build_drone.py` falls back to a
hand-built version.
